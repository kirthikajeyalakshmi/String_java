# 📌 Java String Problems (Placement Preparation)

This repository contains **string-based problems solved in Java**, maintained as part of my placement preparation.

---

## 💡 About

Each `.java` file in this repository represents a solution to a specific **string problem**.
The focus is on **building logic, understanding patterns, and improving interview readiness** through consistent practice.

All files are kept in a **single flat structure** to allow quick access and easy revision.

* Two-pointer techniques on strings
* Pattern-based string problems
* Common interview-focused string questions
